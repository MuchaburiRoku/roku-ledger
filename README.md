# roku-ledger

YouTubeチャンネル「無茶振られAI ロク」の運営台帳です。再生数、登録者、かかった費用と時間、失敗した判断、外れた予想まで、運営の実測を全部ここに記録します。

## このチャンネルについて

- チャンネル: [無茶振られAI ロク](https://www.youtube.com/@MuchaburiRoku)（@MuchaburiRoku、2026-11-25開設）
- AI（ロク）が企画、台本、制作、運営を担い、人間の編集長（Junya）が判定だけを行う実験チャンネルです。「AIに全部やらせたら、本当に稼げるのか」を、主張ではなく実測で確かめます。
- コンセプトは一文でこうです。「『実測さえあれば、始めるか判断できるはず』という思い込みを、実測の台帳でひっくり返す」
- 編集長の無茶振りと却下がフリ、AIの工夫が中身、最後は数字が審判してオチがつく。その判定の記録も、この台帳に残します。

## チャンネルの約束

- 数字は全部出す。都合の悪い数字（伸びなかった週、外れた予想、捨てた企画）も隠さない。
- 予想は、結果が出る前に、日付入りでこの台帳に記録する。後から書き換えない。間違っていた場合の訂正は、元の文を消さずに追記で残す。
- 続ける条件と撤退ラインは先に宣言する。撤退基準は「悲観シナリオの状態が約6か月（2クール）続いて、改善の兆しがない場合」に、撤退か大幅な組み直しを検討する、というもの。最終判断は編集長が行う。
- 人間の手間も実測して出す。「AIが全部やる」と言いながら、編集長が判定や確認に何分使ったかも台帳に書く。

## 検証の物差し（検証グレード）

数字の格付けは項目単位で付けます。軸は1つ、「第三者が、主張者の管理下にない情報源で、その数字を再確認できるか」です。

- 再確認できる一次情報: プラットフォーム上で第三者が直接見られる公開値（チャンネルの登録者数など）
- 本人の一次記録: 本人が公開した台帳、運用ログ、アナリティクスの画面。一次資料ではあるが、置き場所と改変の可能性が本人の管理下にあるため、第三者の再確認は不可。この台帳の数字の多くはこの区分で、正直にそう書く
- 二次情報: 第三者による報道やまとめ
- 自己申告のみ: 裏付け資料の提示自体がないもの

## 台帳の置き方

- `weekly/` に週次台帳を置く。形式は `weekly/template.md` の通り。
- このリポジトリのコミット履歴を正本とする。過去の数字を書き換えれば履歴に残るので、「書き換えていないこと」自体を履歴で確かめられる形にしてある。
- 生データの置き場所はここに固定し、引っ越ししない。

## 目標（定点表示）

- 登録者 1,000人
- 長尺の総再生時間 8,000時間

いずれも2027年2月1日からのYouTubeパートナープログラム新規申請条件。現在地は週次台帳の定点表示に毎週書く。
